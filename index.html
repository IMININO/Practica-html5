Felion System

Un espacio para aprender sobre informatica y tegnologia.

¿Que puedes aprender en Felion System?

  • Reconocer las partes de una computadora.
  • Organizar archivos y carpetas.
  • Utilizar aplicaciones básicas.
  • Navegar por internet de forma segura.
  • Crear páginas web con HTML5.

Pasos para crear tu primera página web

  1. Crear una carpeta para el proyecto.
  2. Abrir la carpeta en Visual Studio Code.
  3. Crear el archivo index.html.
  4. Escribir la estructura y el contenido HTML5.
  5. Guardar el archivo y abrirlo en el navegador.
