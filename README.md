# Práctica HTML5: Balatro

Página web sobre Balatro creada como práctica de HTML5.

Incluye etiquetas semánticas, encabezados, párrafos, listas
ordenadas y desordenadas, una imagen con texto alternativo
y enlaces internos y externos.

## Páginas

- index.html: presentación de Balatro.
- pages/nosotros.html: información sobre el proyecto.
- pages/contacto.html: información del autor.

## Cómo abrir el proyecto

Abrir index.html en un navegador web.
